# Hued — Discovery package

Bienvenido al paquete de discovery de **Hued** — la app móvil que convierte cualquier foto en un infográfico de paleta de colores editorial-grade y compartible.

## 📦 Contenido del paquete

| Archivo | Propósito | Cuándo usarlo |
|---|---|---|
| **PRD.md** | Product Requirements Document siguiendo metodología Double Diamond | Antes de cualquier decisión de scope o feature |
| **SCHEMA.md** | Arquitectura técnica, data models, ADRs | Antes de tocar código en cada sprint |
| **SPRINTS.md** | Plan de 6 sprints día por día con tickets accionables | Cada mañana al arrancar el trabajo |
| **START.md** | Instrucciones exactas para arrancar Sprint 0 con Claude Code | Una sola vez, al iniciar el proyecto |

## 🚀 Cómo empezar

1. Lee **PRD.md** completo (15 min) para internalizar el "por qué"
2. Lee **SCHEMA.md** §1-§3 (10 min) para entender el "cómo"
3. Lee **SPRINTS.md** overview + Sprint 0 (10 min) para entender el "cuándo"
4. Sigue **START.md** paso a paso para arrancar Sprint 0 hoy

Total de lectura: ~35 min antes de escribir la primera línea de código.

## 🧭 Filosofía del paquete

Este paquete sigue la metodología que ya conoces de tu guía integral:

```
Double Diamond              Execution
─────────────────           ─────────────────
Discover  →  Define  →  →   Develop  →  Deliver
(PRD)        (PRD)          (SCHEMA + SPRINTS)
                            (START)
```

PRD captura los dos primeros rombos (problema + solución). SCHEMA + SPRINTS bajan al detalle de ejecución. START es el "primer puente" entre planificación y código.

## 🎯 North Star

Si en cualquier momento del proyecto te encuentras dudando sobre una decisión, vuelve a este principio:

> Hued is the fastest way to turn a photo into a shareable color story. Point your camera, pick a layout, share. Built for people who see in color.

Cualquier feature que no acelere ese flujo está fuera de scope en MVP.
